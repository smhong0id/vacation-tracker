# Google Sheets → Firebase 휴가 동기화

Slack 워크플로가 기록하는 **`휴가일정`** 시트를 Firebase Realtime Database의 `people/{id}/used_leaves`에 반영합니다.

## 시트 형식

**`휴가일정`** 탭 (1행 헤더):

| 휴가자 | 휴가 시작일 | 휴가 종료일 | 동기화 |
|---|---|---|---|
| 홍수민 (여름 휴가) | 2026-09-07 | 2026-09-11 | 완료 +5 |
| 박규태(오전반차) | 2026-09-08 | 2026-09-08 | 완료 +1 |

- **동기화** 열(D열): 스크립트가 자동 기록합니다. `완료`인 행은 다시 처리하지 않습니다.
- (선택) **`공휴일`** 탭 A열에 `YYYY-MM-DD`를 추가하면 내장 공휴일 목록에 더합니다.

## 반영 규칙

| 항목 | 규칙 |
|---|---|
| 날짜 | 시작일~종료일 **포함**, **주말 포함**, **공휴일 제외** |
| 이름 | 괄호 앞 텍스트 = `people.name`과 **완전 일치** |
| 사유 | 괄호 안 텍스트 → `reason` (괄호 없으면 빈칸) |
| 반차 | `휴가자` 칸에 **반차** 포함 시 0.5일 · `반일 휴가` |
| 그 외 | 1일 · `하루 휴가` |
| 중복 | 같은 사람·같은 날짜 이미 있으면 **건너뜀** |

## 설치 (1회)

### 1. Apps Script 연결

1. Google Sheets(휴가일정이 있는 스프레드시트) 열기
2. **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 이 폴더의 `Code.gs` 전체로 **붙여넣기** 후 저장

### 2. Firebase 인증 (RTDB 규칙이 열려 있으면 생략 가능)

Firebase 콘솔 → Realtime Database → 규칙이 테스트 모드(읽기/쓰기 허용)면 **인증 없이** 동작할 수 있습니다.

규칙을 닫았다면:

1. Apps Script → **프로젝트 설정 → 스크립트 속성**
2. `FIREBASE_AUTH` = Database secret 또는 legacy token

### 3. 수동 테스트

Apps Script 편집기에서 함수 `syncVacationSheet` 선택 → **실행**

처음 실행 시 Google 권한 승인이 필요합니다.

### 4. 자동 실행 (5분마다)

편집기에서 함수 `installTrigger` 실행 → 5분마다 새 행 동기화

중지: `removeTrigger` 실행

## 동기화 결과 예시

| 동기화 열 값 | 의미 |
|---|---|
| `완료 +3` | 3일치 휴가 추가 |
| `완료(중복2)` | 모두 이미 등록됨 |
| `완료 +2 중복1` | 2일 추가, 1일 중복 스킵 |
| `오류: 미등록 김애진` | Firebase `people`에 이름 없음 |
| `완료(적용일 없음)` | 기간이 공휴일만 포함 |

## 팀원 이름 맞추기

Firebase에 등록된 `name`과 시트 **휴가자**의 이름이 같아야 합니다.

- `홍수민 (당직휴가)` → DB 이름 `홍수민`
- `박규태(오전반차)` → DB 이름 `박규태`

앱에 없는 사람은 먼저 **계정 만들기**로 등록하세요.

## 공휴일 갱신

- `Code.gs`의 `BUILTIN_HOLIDAYS` 배열을 매년 수정하거나
- 시트 **`공휴일`** 탭 A열에 날짜 추가
